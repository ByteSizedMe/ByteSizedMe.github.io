# Project rules
- The full design spec is in SPEC.md. The ADDENDUM in it overrides earlier sections where they conflict. Read it fully before each batch.
- Vanilla HTML/CSS/JS only. No frameworks, no build step, no npm dependencies. Relative asset paths only.
- All content lives in js/content.js. Never invent facts about me: unknown values are clearly marked TODO.
- Work only on the current batch. Do not build ahead.
- Do NOT open PRs, do NOT make commits, do NOT push. At the end of each batch, give me a commit plan: suggested commit messages and the exact `git add` paths for each. I make the commits and PRs under my own name.
- After each batch, stop, summarize what was built, list how to test it, and wait for my review.
